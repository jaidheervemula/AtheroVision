# heart.glb

Built from **BodyParts3D** © DBCLS (CC BY-SA 2.1 Japan) by `tools/build_heart_model.py`.
Contains named nodes `LAD`, `LCX`, `RCA`, `LeftMain`, `Myocardium_LAD/LCX/RCA`, `LeftAtrium`,
`RightAtrium`, `Aorta`, `PulmonaryTrunk`, `SVC`, `IVC`. This file is a derivative of BodyParts3D
and is distributed under the same CC BY-SA 2.1 JP licence; credit DBCLS when you share it.

To use a different heart model, replace this file. If the new model has no `LAD`/`LCX`/`RCA`
nodes, the app overlays its procedural vessels on it and offers an Align panel. Save the
alignment JSON next to it as `heart.json` to share it with the team.
